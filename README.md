# 咒术闲录

一个单机 / 局域网对战的放置养成游戏，世界观取材《咒术回战》。
界面全部由 CSS、字符与 SVG 实时绘制，不含任何商业游戏的素材。

## 下载与运行

- 进 [`release/`](release) 目录，把里面的文件全部下载到同一个文件夹（`咒术闲录.exe` 及同级的 dll / pak / resources 都不能少）。
- 双击 `咒术闲录.exe` 即可，免安装、免联网。
- 存档与音乐都在程序文件夹内的 `userdata\`，不会写到别处。

> `咒术闲录.exe` 走 Git LFS 存放，直接点网页上的 “Download” 会被重定向到 LFS 的地址；
> 如果下载得到的是一百多字节的文本文件，请改用 `git lfs install` 后 `git clone` 本仓库。

## 都在包里

玩法说明、自定义目录（出身 / 术式 / 敌人 / 地图 / 立绘 / 见闻……）的写法，
都写在 [`release/readme.md`](release/readme.md) 里，游戏内「说明」页也有同样一份。
