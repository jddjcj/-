# 咒术闲录

一个单机 / 局域网对战的放置养成游戏，世界观取材《咒术回战》。
界面全部由 CSS、字符与 SVG 实时绘制，不含任何商业游戏的素材。

## 怎么下载（推荐）

去 [Releases](https://github.com/jddjcj/ZhouShuSianLu/releases/latest) 下载 **`ZhouShuSianLu-v1.0-portable.zip`**，
解压后双击里面的 `咒术闲录.exe` 即可，免安装、免联网。

> 请**不要**用右上角 "Code → Download ZIP"：本仓库用 Git LFS 存 exe，
> 源码包里的 `咒术闲录.exe` 只是一个 134 字节的指针文本，没法运行。Release 附件才是完整文件。

## 其它下载方式

- 只补 exe：打开 [`release/咒术闲录.exe`](release/咒术闲录.exe) → 右上角 "Download raw file"（235 MB）。
  把它放进已解压的同一层目录即可。
- 会用 git：`git lfs install` 之后 `git clone https://github.com/jddjcj/ZhouShuSianLu.git`。

## 都在包里

玩法说明、自定义目录（出身 / 术式 / 敌人 / 地图 / 立绘 / 见闻……）的写法，
都写在包内的 `readme.md` 里，游戏内「说明」页也有同样一份。
