# 自定义特效间隔（多图连播：每张图停留多久）

给「术式特效」配了一串图（`fx__术式id.1.png`、`.2.png`、`.3.png`）之后，
一张一张过的节奏就由这个夹子说了算 —— **每一张图停留多少毫秒**（也就是与下一张之间隔多久）。
不配就用本体的默认（每张 450ms）。

配好的效果：技能先把这串图按你给的节奏放完，**放完了才结算伤害与效果**。

## 怎么写

复制 `_模板.js`、改名（别用 `_` 开头），把里面 push 的那几行放出来改成自己的；
或者复制 `_模板.json`、改名，直接写成纯数据（不想碰代码就用它）。

```js
window.JH_CUSTOM.特效间隔.push({
  match: { skill: 'k_punch' },       // 命中哪一门术式（见下表）
  ms: 200,                          // 每张图停留 200ms
  frames: [120, 200, 340],          // 可选：逐张指定（第 1 张 120、第 2 张 200、第 3 张起 340）
  first: 300,                       // 可选：只调第一张
  last: 700                         // 可选：只调最后一张
});
```

## 字段

| 字段 | 意思 |
| --- | --- |
| `match` | 命中规则，和「自定义特效」一模一样：`skill` / `innate` / `dom` / `kind` / `id`（任填其一或组合）。**不写 match = 兜底默认**，谁都命中不到时才轮到它 |
| `ms` | 每张图停留多少毫秒（= 与下一张的间隔） |
| `frames` | 逐张指定的一组毫秒数：第 i 个数管第 i 张，不够的张数沿用最后一个数 |
| `first` | 只改第一张的停留（优先于 `ms`） |
| `last` | 只改最后一张的停留（优先于 `ms`） |
| `default` | 兜底默认间隔（不写 match 的那一条里，`default` 与 `ms` 都行） |

越具体的越优先：`skill`/`id` > `innate` > `dom` > `kind` > 兜底；一个技能只吃一条。
毫秒数最小按 40 算（写 0 / 负数会被忽略，回落到 Default）。

只配了一张图（没有 `.1.png` / `.2.png` / `.3.png` 这种编号）时这个夹子不起作用 —— 那走的是单张特效。
本体不会往这个夹里写任何东西；这里只有这份 README 与两个模板。
接口在 `app/js/imgcustom.js`（`JH_IMGC_fxSeq` / `JH_IMGC_SEQ_MS`）。
