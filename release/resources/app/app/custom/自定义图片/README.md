# 自定义图片

给你自己（或别的玩家）放图片素材的抽屉：立绘、头像、自定义面板的底图……直接丢进来就行。

**本体不自带任何图片** —— 界面全是 CSS / 字符画出来的。这里的图片**不会被自动加载**，
只有你的自定义内容用到它们、或按下面的文件名规则挂了槽位时才会出现，
所以放多少张都不会拖慢启动、也不会进对话上下文。

## 规矩

- 认这些格式：`.png` `.jpg` / `.jpeg` `.gif` `.webp` `.bmp` `.svg`；其它文件忽略。
- 文件名用英文 / 数字最稳（除非你在用下面那套「槽位命名」）；重名会被后放的盖掉。
- 在自定义脚本里用 `window.JH_IMG("my_hero.png")` 就能拿到它的相对路径
  （结果是 `custom/自定义图片/my_hero.png`，可以直接 `<img src=...>`）。
- 图片名（清单）在 `window.JH_CUSTOM_IMAGES` 里，按文件名排序。

## 大小自适应（你只管丢图，界面自己缩放）

四种槽位都**按容器等比缩放**，不用你自己裁尺寸：

- **打斗背景 / 舆图底板**：铺满整块、居中、按比例裁掉多出来的边（`cover`）—— 横图竖图都不会拉变形；
- **人物建模**：塞进小人框里等比缩放、贴地居中（`object-fit:contain`）—— 多大的图都不会撑破版面；
- **术式特效**：铺满整块特效层、等比缩放居中（`contain`）。

建议：素材**长边 ≥ 768**（太小放大后发虚）；人物建模用**透明底 PNG**、竖幅立姿最好看；背景用横幅 16:9 上下。
真要精确控制的，可以在自己的自定义脚本里另外给元素加 CSS（本体的规则只保证「不变形、不溢出」）。

## 纯色底自动抠除（人物建模 / 术式特效）

**人物建模（`actor__`）与术式特效（`fx__`）这两类图，会自动把「和画面边缘连成一片的纯色底」抠成透明** ——
白底的立绘、绿布底的人物，不用你自己先抠好，直接丢进来就行。

- 只吃**从边界灌得进去**的那一片同色像素：衣服里头、头发缝隙里同样颜色的地方**不会被误伤**（不连通）。
- 收尾会向里收 1 像素，把抗锯齿留下的那圈毛边一并去掉。
- **四个角凑不出三个同色底**（画面正好贴满边、人物压到角上）时，宁可不抠 —— 免得把人物自己削掉一块。
- 抠出来的永远是 **PNG**（带透明通道），长边超过 2048 的会先等比缩到 2048 再抠。
- 不挑素材格式：PNG / JPEG 由主进程直读；GIF / WebP / BMP / SVG（含「扩展名写着 .png、里头其实是 WebP」的图）也能抠 —— 主进程读不出的，改由浏览器解码后再走同一套规则，效果一样。
- **背景类（`battle__` 打斗画面 / `map__` 大地图）与领域换底图（`battle__dom.*`）不抠** —— 那本来就是整张底图。
- 想留底就把底色改成不连成一片的花色（渐变、图案、马赛克都行），它就认不出「哪一片是底」了。

抠底在主进程里用游戏自带的读图能力完成，不联网、不加任何第三方库；同一张图只抠一次（按「路径 + 修改时间」缓存）。

## 一、文件名自动挂（丢进去就生效，不用写代码）

前缀 `__` 槽位名，`__` 后面那截决定挂在哪儿：

| 文件名 | 换掉的东西 |
| --- | --- |
| `battle__default.png` | 打斗画面（对战框）的默认背景 |
| `battle__sc_home.png` | 只在某一处场景里用（这里是「自宅」，用场景 id） |
| `actor__hero.png` | 打斗时**我方**的建模（火柴人换成人像） |
| `actor__foe.png` | 打斗时**敌方**的建模（通用） |
| `actor__f_b_kyo.png` | 某一个敌人 id 的建模（比如某个头目专门放一张） |
| `actor__o_sukuna.png` | 我方某一个出身 id 的建模 |
| `fx__default.png` | 术式特效的兜底图（没有更具体的就用它） |
| `fx__k_punch.png` | 某一门术式的特效（用术式 id） |
| `fx__t_csm.png` | 某一系生得术式的特效（用生得术式 id） |
| `fx__domain.png` | 领域展开：所有领域通用 |
| `fx__domain.infoOverload.png` | 领域展开：某一种领域（用 domKind） |
| `battle__dom.infoOverload.png` | **领域换底**：某个领域（谁那方领域血厚就显示谁的图） |
| `battle__dom.hero.png` / `battle__dom.foe.png` | 领域换底：固定我方 / 敌方的底 |
| `battle__dom.png` | 领域换底：不分谁那方的兜底 |
| `fx__summon.png` | 召唤物登场 / 驱使 |
| `fx__phy.png` / `fx__bf.png` | 普通攻击 / 黑闪 |
| `map__default.png` | 山河舆图的默认底板 |
| `map__rg_nordic.png` | 某一座大地图的底板（用大地图 id） |

槽位名大小写不敏感；同一个槽位放多张，按文件名排序取第一张。

## 二、在自定义脚本里手动绑（比文件名更准）

```js
JH_IMGC_bind('actor', 'foe', 'my_boss.png');   // 大类 / 槽位名 / 图片
JH_IMGC_bind('fx', 'skill.k_punch', 'punch.png');
JH_IMGC_unbind('actor', 'foe');                // 解绑，回到原来那张 / 纯 CSS

JH_IMGC.url('fx', 'skill.k_punch');            // 取路径（没有就返回空串）
window.JH_IMGC.entries();                      // 现在实际生效的槽位清单
```

四大类：`battle`（打斗画面）/ `actor`（人物建模）/ `fx`（术式特效）/ `map`（大地图背景）。
图片只「换个样子」，不改任何数值与机制；删掉图片，界面立刻回到纯 CSS 的样子。

**放图就顶掉代码特效**：配了图的那一条（某一门术式 / 某系生得术式 / 领域 / 招式类别），
只出你的图，本体原本用 CSS / 字符 / SVG 画的墨戏整段让位 —— 不会再两层叠在一起。

**领域换底**：领域展开的时候，领域图会临时替掉整个打斗背景：谁那方的领域血更厚，底就是谁的；
两边都没领域了，自动还回原来的背景（或 `battle__` 那张）。底图铺满整框、压在小人下面，**不会盖住人物建模**。

## 三、想连「代码」一起写：去隔壁「自定义特效」

只想换一张图，上面两节就够了。如果想让技能演出是**代码 + 图片**拼出来的
（自己写 HTML 段 + 配几张图 + 一段 CSS），去 `app/custom/自定义特效/` 那一夹看它的 README；
那边的配方压过这里的 `fx__` 静态图（有配方就用配方）。

## 随便放，不会坏事

图片不是 .js，装载器不会拿它当代码执行；写坏了也只是那张图显示不出来而已。
