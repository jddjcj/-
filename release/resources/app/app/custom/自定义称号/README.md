# 自定义称号

称号（**本体暂未接入** —— 这里先按模板登记，等本体支持后再生效）。

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一 id（`x_` 打头）与名字 |
| `desc` | 说明 |
| `req` | 拿到它的条件（写法参考场景解锁 `unlock`：`{ realm, insight, flag, story }`） |
| `hidden` | `true` = 先不出现在图鉴里 |

> 说明：这一栏是给以后留的坑位。装载器会把它收进 `window.JH_CUSTOM.称号`，
> 但本体还没有「挂称号」的地方 —— 等本体做了，写在这里的就会跟着一起生效。
