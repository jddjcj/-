# 自定义敌人

场景里刷的敌手与头目（进 `JH_FOES`）。**注意：敌我数值是陪你一起长的** ——
不是写死几万血，而是写「它该挨几下」，本体按你当前的强度把它折算出来。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一 id（`x_` 打头）与名字 |
| `scene` | 刷在哪个场景（本体场景 id，如 `sc_shibuya`） |
| `lvl` | 等级，决定它与你对打的档次 |
| `rounds` | 预期能撑几个回合（**这就是血量**：越多越厚） |
| `margin` | 强度系数，越大越容易打（1.5 是常例） |
| `defF` | 防御系数（`pb.def × defF`） |
| `phyRes` | 物理减伤（0~1） |
| `curRes` | 咒力减伤（0~1） |
| `dmgType` | 它打你的是 `phy` 还是 `cur` |
| `human` | `true` = 算「人」，不吃收服那一套 |
| `skills` | 它会用的术式 id 数组 |
| `boss` | `true` = 头目 |
| `dummy` | `true` = 木桩（血厚到打不完，给你试招用） |
| `dom` | 它会开的领域（术式 id）；`endlessDom:true` 才让它领域血量无限 |
| `loot` | 掉落表：`[[物品id, 概率0~1, 数量]]` |

**不要写无限血 / 无限咒力**：本体不给敌人这种待遇，领域血也是按它自身强度算出来的。
