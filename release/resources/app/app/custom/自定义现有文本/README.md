# 自定义现有文本

把本体（以及其它自定义内容）里**已经有的名称 / 说明**换成你自己的说法。
装载器启动时按你写的顺序把本体数据走一遍**纯文本替换**。

## 写法

| 字段 | 说明 |
| --- | --- |
| `from` | 要被换掉的原文 |
| `to` | 换成什么（写空串 = 删掉） |

只动这几个字段：`name` `desc` `note` `title` `daily` `master`；**id 一律不动**，
所以替换只是换皮，存档、联动、解锁都不受影响。

## 例子

| from | to |
| --- | --- |
| 蝇头 | 小飞虫 |
| 咒力缠绕 | 缠咒 |

## 三条注意

1. 挑词越独特越安全 —— 别写「咒力」「领域」这种满世界都是的词。
2. 一条一条按顺序套用：先 `甲→乙`、再 `乙→丙`，结果就是 `丙`。
3. **剧情正文不在这里改** —— 要改剧情请用「自定义剧情」文件夹。
