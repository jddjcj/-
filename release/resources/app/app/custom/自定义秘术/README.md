# 自定义秘术

秘传术式：**不是买得到的，是有人肯教才学得到的**。写在这里的术式会进 `JH_MARTIAL`，
但学习条件靠自己声明，再在「自定义npc」里安排一个肯教的 npc（两个文件夹是联动的）。

## 怎么写一条秘术

1. 在这里写一条术式（写法和「自定义普通术式」完全一样），再加上：

| 字段 | 说明 |
| --- | --- |
| `secret` | `true` = 图鉴里标成秘传 |
| `req` | 传授门槛，见下表；不满足就教不了 |
| `passive` / `nei` / `qing` / `eff` | 同普通术式，机制照旧 |

`req` 能写的门槛（都是「不到就不教」，可任意组合）：

| 键 | 含义 |
| --- | --- |
| `insight` | 悟性下限 |
| `root` | 根骨下限 |
| `face` | 颜值下限 |
| `faceMax` | 颜值**上限**（颜值太高的人不教 —— 本体「空刃」就是这种） |
| `luck` / `luckMax` | 福缘下限 / 上限 |
| `realm` | 境界下限 |

2. 再去「自定义npc」里给某个 npc 加上：

```js
teach: { skill: "x_secret_edge", aff: 88, task: "ch6", secret: true }
```

`aff` = 好感下限，`task` = 要先替他办成的主线（可省），`secret: true` = 学成时记一条【秘传】流水。

## 秘传的设计建议

秘传要**半通用、有机制**：别只是数值大一点，而是给一条别处拿不到的机制
（例如「挨打时把伤害改成回血」「逃跑失败反而先手」这种），条件也写得刁一点 ——
颜值过高、福缘过低、根骨达标但悟性不足，都行。
