# 自定义特效（技能演出：代码 + 图片）

这个夹子给你的技能演出开了一个「自己写」的口子：一门术式 / 一系生得术式 / 一个领域 /
一类动作（黑闪 / 普通攻击 / 术式 / 召唤 / 领域展开）的演出，可以换成

- **代码**（一段 HTML，用本体已有的 `.ink` 墨戏 class，或自己配 CSS）；
- **图片**（放「自定义图片」夹里，配方里写文件名）；
- 两者随意组合 —— 只写代码、只放图片、或代码 + 好几张图都行。

**优先级**：有配方就整段用配方（本体原本的墨戏不再画）；没有配方时才看
「自定义图片」里 `fx__` 那张静态图；都没有才用本体的墨戏。所以这份配方永远压过图片。

## 怎么写

复制 `_模板.js`、改名（别用 `_` 开头），把里面的 `window.JH_CUSTOM.特效.push({...})`
放出来改成自己的即可。也可以写成 `.json`（一个对象或一个对象数组）。

```js
window.JH_CUSTOM.特效.push({
  match: { skill: 'k_punch' },                     // 命中哪一门术式
  code: '<div class="ink ink-skill"></div>',        // 代码部分
  imgs: ['punch.png', { file: 'fist.png', size: '40%', delay: 120 }],
  css: '.my-ring{ ... }',                           // 可选：给这段代码补的 CSS（全局注入一次）
  delay: 0                                          // 可选：整段延后多少毫秒
});
```

`match` 可写（任填其一或组合；一条都不写 = 万能兜底，最后才轮到）：

| 键 | 意思 | 例子 |
| --- | --- | --- |
| `skill` | 某一门术式 id | `k_punch` |
| `innate` | 某一系生得术式 id | `t_csm` |
| `dom` | 某个领域的 `domKind` | `infoOverload` |
| `kind` | 动作类别 | `bf` / `phy` / `ink` / `summon` / `domain` |
| `id` | 术式 id 或生得术式 id 都认 | `t_csm` |

越具体的越优先：`skill`/`id` > `innate` > `dom` > `kind` > 空；一个技能只命中一条。

`imgs` 里每一项可以是字符串（文件名），也可以是对象：

| 字段 | 意思 |
| --- | --- |
| `file` | 图片文件名（放「自定义图片」夹里），或整条相对路径 |
| `size` | 宽度（如 `'40%'` / `'320px'`）；只给宽度，高度按比例自适应 |
| `left` / `top` | 图片中心的位置，默认 `50%` / `50%`（正中央） |
| `pos` | 图片在框里的 `object-position`，默认居中 |
| `delay` | 这张图晚多少毫秒出现 |
| `plain` | `true` = 不抠底；默认会自动抠掉连着边缘的纯色底 |

图片默认居中、等比缩放、最大不超过整框 —— 多大的图都不会撑破版面。

**多图连播的节奏**（一串图每张停留多久）不在这个夹里配 —— 见隔壁 `自定义特效间隔/`；
这一夹只管「演出长什么样」，那一夹管「一张一张过多快」。

本体不会往这个夹里写任何东西；这里只有这份 README 与 `_模板.js`。
接口在 `app/js/imgcustom.js`（`JH_FXC_of` / `JH_FXC_html` / `JH_FXC_css`）。
