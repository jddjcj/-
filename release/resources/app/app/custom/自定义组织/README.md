# 自定义组织

组织（`JH_SECTS`）：自己的势力、自己的成员、自己的特有术式。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一 id（`x_` 打头）与名字 |
| `align` / `color` | 正 / 中 / 邪，与显示色 |
| `desc` | 说明 |
| `req` | 加入条件：`{ insight, root, realm, flag }` |
| `master` | 负责人（求教用，写个名字） |
| `hidden` | `true` = 要相应旗标才露面 |
| `skills` | 这个组织**特有**的术式 id（写在「自定义普通术式」或「自定义秘术」里） |
| `shop` | 贡献兑换表：`[[物品或技能 id, 贡献价]]` |
| `daily` | 每日事务的一句话说明 |
| `members` | 组织成员（npc id 数组）—— 每日对练就是和他们练 |
| `allCommon` | `true`（默认）= 这个组织**默认能教所有普通术式**；写 `false` 关掉 |

## 两条默认规矩

1. **所有组织默认可以学习所有普通术式**。所以你不写 `allCommon` 也行 ——
   装载器会把这个组织该教的（`JH_COMMON_ALL` 里那批 `common:true` 的术式）
   自动补进 `shop`，价钱按本体的常规价位。要按自己的价钱来，就自己在 `shop` 里写一遍
   （写了就不重复补）。
2. `members` 里的人会跟着这个组织走：**退出组织时，这些成员里好感为正的会被一并清零**
   （本体规矩：同门的情分断起来是断干净的），而且一个角色一生最多加入 3 个组织。

## 成员的写法

成员必须是「自定义npc」文件夹里存在的 npc id；`JH_SECT_MEMBERS` 会被自动填好，
每日对练会从里面随机刷人（最少 1 个、最多 4 个，每人每天陪练 3 次）。
