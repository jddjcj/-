# 大自定义文件夹（custom）

这个文件夹是**留给玩家**的。游戏本体不动这里；你往里面放东西，游戏启动时会自动装进来。
整个 `app/custom/` 可以单独打包、原样分享给别人。

## 规矩（很重要）

1. 每个子文件夹里都有一份 `_模板.js`：**复制它、改名**（不要用 `_` 开头），
   再把里面注释掉的那段放出来、改成你自己的内容。
2. `_` 开头的文件会被跳过（模板就是这么放着的），`README.md` 也不会被加载。
3. 每个 `_模板.js` 里都逐字段写了注释（每个参数是干什么的），拿不准就看那边。
4. 自定义内容之间靠 **id** 互相引用（自定义 npc 的 `teach.skill` 指向自定义秘术的 id、
   自定义装备的 `words` 指向自定义咒具词条的 id……）。id 一律用 `x_` 打头最保险，免得和本体撞车。
5. 写坏了不会崩游戏：某个文件报错只会被跳过，并在控制台留一行警告。
   但**同 id 会覆盖**（后加载的盖先加载的），所以别重复。
6. 每个夹里能放 `.js`（脚本）或 `.json`（纯数据）；`.md` 与图片不会被当代码加载。
   `_` 开头的文件、`README.md` 一律跳过。

**图片替换**（只想换画面、不动数据的最省事路子）：把图片丢进 `自定义图片/`，文件名写成
`打斗画面/人物建模/术式特效/大地图背景` 里对应的前缀即可，详见那一夹的 `README.md`；
接口在 `app/js/imgcustom.js`（`JH_IMGC` / `JH_IMGC_bind` / `JH_IMGC_battle|actor|fx|map`）。

- **放图就顶掉代码特效**：配了图的那一条只出你的图，本体原本用 CSS / 字符画的墨戏整段让位（不会两层叠着）。
- **领域换底**：领域展开时，领域图会临时替掉整个打斗背景 —— 谁那方的领域血更厚就显示谁的，
  两边都没领域了自动还回原来的背景；底图铺满整框、压在小人下面（不盖人物建模与人物图）。
  想按方配：`battle__dom.<领域domKind>.png` / `battle__dom.hero.png` / `battle__dom.foe.png`，
  都没配就退回 `fx__domain.<domKind>.png`。领域换底图**不抠底**。
- **自定义特效**（`自定义特效/`）：技能演出可以自己写 —— 一份配方 = 一段 HTML 代码 + 若干张图 + 可选 CSS，
  详见那一夹的 `README.md` 与 `_模板.js`；接口是 `JH_FXC_of / JH_FXC_html / JH_FXC_css`。
- **多图连播的间隔**（`自定义特效间隔/`）：一串图一张一张过，每张停留多久在这里配（`ms` / `frames` / `first` / `last`），
  不配就用本体的 450ms/张；**放完最后一帧才结算伤害**。接口是 `JH_IMGC_fxSeq`（`app/js/imgcustom.js`）。

装载器是 `app/js/custom.js`，在 `app/index.html` 里排在 `js/base.js`（本体内容，来自 `app/base/`）之后、
`js/engine.js` 之前 —— 所以自定义内容会和本体一起进索引，
引用本体的 id（材料、场景、技能）完全没问题。

> 给后来的协作者（含 AI）：**除非用户特地要求，否则不要往这个文件夹里写任何内容。**
> 这里只提供文件夹和模板；内容由玩家自己填。唯一的例外是 `扩展地图/镜屋.js` ——
> 那是本体功能（镜屋）的房间表，按用户要求从本体房间表（现在在 `app/base/地图/地图.json`）搬到了这里。
