# 自定义装备

兵器 / 护具 / 配饰 / 靴子（进 `JH_ITEMS`，靠 `type` 分栏）。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一 id（`x_` 打头）与名字 |
| `type` | `weapon` 兵器 / `armor` 护具 / `charm` 配饰 / `boots` 靴子 |
| `q` | 品质 1~7 |
| `price` | 售价（商店、卖店都用它） |
| `stack` | **装备一律写 1**（装备不堆叠） |
| `stats` | 加成：`{ phyAtk, curAtk, def, dodge, curMax, hp, crit, esc … }` |
| `desc` | 说明 |

## 和「自定义咒具词条」怎么联动

装备本身不带词条：**先把它咒具化**（本体锻冶页，需要某一类特殊出身），
再到锻冶页**抽词条** —— 抽的就是「自定义咒具词条」文件夹里的那个池子。
所以两个文件夹是这样联动的：

- 这里定义**能被咒具化、能刻词条的东西**（`type` 是 weapon/armor/charm/boots）；
- 那里定义**能刻上去的机制**（`JH_WORDS`）。

一件咒具最多刻 3 条（强化到 +3 / +6 / +9 各开一槽），标 `once:true` 的词条一件只能刻一条。
