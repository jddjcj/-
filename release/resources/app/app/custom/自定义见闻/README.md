# 自定义见闻

右侧「见闻」栏现在是**一本可以左右翻的画册**：

- 第 0 页 = 原本的流水（打怪、掉落、剧情……）；
- 往后每一页 = 你丢进这个文件夹的**一张图或一段视频**；
- 栏头左边是「‹」、右边是「›」：翻到最后一页再按「›」会**绕回流水**（循环）；在流水页按「‹」直接跳到最后一页。
- 停在某一页上，那一页的**视频就一直放着**（自动播放 + 循环）；翻走时它自己停。

**放进来就生效，不用写任何代码。**

## 规矩

- 认这些格式：
  - 图片：`.png` `.jpg` / `.jpeg` `.gif` `.webp` `.bmp` `.svg` `.avif`
  - 视频：`.mp4` `.webm` `.ogv` `.ogg` `.m4v` `.mov`
- **按文件名排序**决定页码顺序 —— 想固定顺序就用 `01_开场.mp4`、`02_立绘.png` 这样编号。
- 视频能不能放，取决于你系统里 Electron（Chromium）解不解得开那个编码：
  最稳的是 **MP4（H.264 + AAC）** 与 **WebM（VP8/VP9 + Opus/Vorbis）**。
- 视频建议别太大（几十 MB 以内），并且**压成 720p 上下**就行 —— 这一栏就巴掌大，太大只是白费内存。
- 文件名用英文 / 数字最稳；中文也能用，但别带 `/` `\` 这些路径符号。
- 本文件夹里**只放图片 / 视频**：`.js` 与 `.json` 不在这儿装（要写脚本请去别的分类夹）。
- 清单在 `window.JH_CUSTOM_MEDIA` 里；自定义脚本里可以用 `window.JH_MEDIA("01.mp4")` 取相对路径。
