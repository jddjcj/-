# 自定义咒具词条

咒具上那些「刻进去的机制」（进 `JH_WORDS`）。本体已有的九条在
`app/base/咒具词条/咒具词条.json`，这里的会**加进同一个池子** —— 锻冶页抽词条时，本体的和你的都在里面。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 唯一 id（`x_` 打头）与名字 |
| `q` | 品质 1~7（决定它在池子里显得多重） |
| `desc` | 说明（**只说效果，不写公式** —— 见闻栏不列公式） |
| `eff` | 机制块，键与本体共用一套 |
| `once` | `true` = 一件咒具最多刻一条（例如「咒术存储」） |
| `rare` | 出现的概率（0~1）。写了 `rare` 的词条从普通池里拿出来单独掷骰，总上限 50% |

## `eff` 能写的机制（本体现成的）

`pierce` 物理穿透 / `combo` 追加一段 / `rebound` 受伤反弹 / `drain` 抽回咒力 /
`bind` 缠住（降逃跑、脱战率，与结界术叠加）/ `slash` 额外斩痕 / `buffer` 首击减半 /
`nullify` 咒力无效化 / `store` 咒术存储。

数值机制照抄本体写法即可；要**新机制**就得改本体 `app/js/combat.js`。

## 和「自定义装备」怎么联动

装备是**能被咒具化的东西**，词条是**刻上去的机制**：
一件兵器/护具/配饰/靴子咒具化并强化到 +3 / +6 / +9 各开一槽，
抽词条时从 `JH_WORDS` 这个池子里抽 —— 你的词条和本体的词条机会均等（`rare` 的影响见上）。
