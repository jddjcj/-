《咒术闲录》· 单机 / 局域网对战的放置游戏（世界观取材《咒术回战》）
=====================================

怎么玩
  双击「咒术闲录.exe」即可，无需安装、无需联网。

数据放在哪
  全部在本文件夹内的 userdata\ 里（存档 save.json、音乐 music\、导出 export\）；没有这个文件夹时会在第一次运行时自动建出来。
  程序不会读写本文件夹以外的任何位置；运行时也已拦截全部网络请求。
  局域网对战用的是临时对局，不写进单人存档。

玩法提要（只讲手感，具体数值与公式都收在游戏里的「说明」页）
  · 顶栏「挂机」= 智能打怪：反复祓除当前场景的杂鱼；下线也按离线时长结算。
  · 修为靠打怪、委托与组织任务攒（剧情只讲故事，不给修为 / 咒币）；满即可「突破境界」。
  · 精力用于搜寻与各种动作，只有「在家中休息」才回；咒力靠休息 / 打坐回。
  · 剧情：条件不足的选项会「暂且搁下」，日后再来。
  · 隐藏剧情与彩蛋：留意人物好感、反复做同一件事、特定时辰站在特定地方，以及某些「密语」。
  · 术式页顶部的几个槽分别挂「当前使用」的主动术式 / 咒力运用 / 体术身法；生得术式学会即整系在手，另占一栏、不挤这几个槽。
  · 术式熟练度只从「加入组织后与同门对练」来：组织页每天会到几位同门，每人每天能陪练几场；赢得多、用得多，涨得就快，单场有上限。
  · 一个人一生最多加入三个组织；退出会清空本门术式、贡献与同门好感。
  · 组织页有「门中人」一栏：把这一门的完整名录列出来（称号 / 好感 / 常在哪个房间 / 今日到没到场），今天到场的能直接点进去对练；名单按「哪一家 + 哪一天」换代。
  · 特殊机制会变成对阵页的独立按键：借术 →「借·X」，收服 →「驱使·X」，「咒术存储」吸到的术式会多出一个「储·X」的按键，不必先按一次机制技能；但要用这类技能给出最后一击，才借得到术式 / 收得进咒灵。
  · 秘传术式：有些东西不写在纸上 —— 多看、多搜、多等，缘分到了自会有人教你。
  · 家里有「练功木桩」与「镜屋」：木桩不还手、不耗咒力，用来试招；镜屋能捏一个跟自己一模一样的对手来试机制。
  · 对阵页有「发呆」：这一回合什么都不做（不耗咒力、不吃冷却），对手照常出手。
  · 术式都有冷却，越强的歇得越久；咒效与咒操高能少歇一点，一场打完自动清空。领域立着的时候再点一次那一门就把它收回，收回 / 被打破 / 咒力见底自散都进同一套冷却。
  · 领域展开要先学普适技能「结界术」；「开放 / 封闭」这套切换手法要更高一档才「会」。闭不闭门都看对阵页「收手」旁边那个「领域形态」按键 —— 只有真使得出来这一门的人才看得见。
  · 每一场开打，领域形态都从「封闭式」起手。
  · 出力 = 生效百分比：滑条调出力，伤害与咒力消耗都跟着走 —— 嫌耗咒高就往下调，代价是挨的伤多一点。
  · 领域一出场就带一条自己的血（摆在护盾槽上面），敌人也按自己的强度算，不是无限。领域血越满强度越高，注力能把血顶回来、被打掉就削下去；两座领域对撞比的就是它。
  · 领域每回合都要吃一笔维持（固定的底子，外加按咒力上限抽的一份）；咒力见底，领域自己就散了。
  · 濒死：一场战斗里敌我各自最多触发一次，触发后会在打斗框里留一句话。
  · 术式熔断：连着甩术式有几率熔断，熔断期间用不出术式，过一阵自己恢复。
  · 攻防、伤害、穿透、领域血量与注力这些公式，都收在游戏里的「说明」页；此处不再赘述。

自定义（给喜欢折腾的人）
  · 那个大夹在 resources\app\app\custom\ —— 里面按用途分了十几个小夹（出身、生得术式、普通术式、秘术、组织、剧情、敌人、npc、地图、称号、道具、装备、咒具词条、现成文本、特效、图片、见闻……）。想让游戏长成你自己的样子，就往对应的小夹里丢文件，格式照每个夹里的 _模板.js 与 README.md 写。本体不会往里写内容 —— 那里只放文件夹与模板。
  · 图片替换：打斗画面 / 人物建模 / 术式特效 / 大地图背景各有自己的文件名前缀，丢进自定义图片夹就会自动顶替原来的画面；配了图的那一条只出你的图，原本用代码画的墨戏整段让位。领域展开还会临时顶掉整个打斗背景 —— 哪一方的领域血更厚就显示哪一方的，两边都没领域了自动还回原来的背景。图片只换样子，不改任何数值；尺寸不用自己裁，背景铺满居中、人物与特效等比缩放。人物与特效图还会自动抠掉「和画面边缘连成一片的纯色底」，白底 / 绿布底的 PNG 直接丢进来就行。动图（GIF / 动画 WebP / APNG）照放、不抠底。
  · 自定义特效：技能演出也能自己写 —— 一段 HTML 代码 + 若干张图，按自定义特效夹里 _模板.js 的字段登记；有配方就整段用配方，没有才看静态图。
  · 舆图 / 大地图：山河舆图上方能左右翻大地图；同一座图里换地方很快，跨大地图是「远渡」，要等得久一些。走到目的地后「所在」页会自己刷新一次。
  · 赶路身法：学了身法 / 瞬移之类的本事，跨大地图能少走一截。
  · 「见闻」页是画册：把图片或视频丢进自定义见闻夹，丢几份就有几页；页顶能左右翻，翻到头会绕回流水；停在某一页上，那一页的视频就一直放着，翻走即停；图片 / 视频都按框自适应大小。
  · 音乐盒（右上角）是自定义的：把想听的歌丢进 userdata\music\，丢多少首就有多少首。游戏不附带任何音频素材（版权），曲目请自备。
  · 「设置 → 自定义内容」一眼看到各个自定义分类各有几条、装了哪些文件、哪里读错了，并能一键打开文件夹。
  · 鼠标悬停在状态小圆片或按键上会弹出作用说明；公式都收在「说明」页，见闻栏只记流水。
  · 第一次进游戏会自动弹一次「新手上路」，之后在「说明」页可以随时打开。

局域网对战
  · 初始界面有「局域网对战」：可以开一个房间等别人进来，两边都点了确认再往下一步；房间只坐两个人，一切数据以开房那一方为准。
  · 对战分几段准备：选出身与生得术式、分技能点与属性点、互相亮牌，双方都确认才正式开打。
  · 对战用的是临时身子，打完即散，不并入单人存档。

关于本作
  《咒术闲录》是原创放置游戏：玩法骨架参考同类商业作品，场景、人物、剧情、数值、界面全部原创，
  与任何商业游戏（包括但不限于《放置江湖》）无隶属或授权关系，也未使用其任何美术 / 音频素材；界面全部由 CSS / 字符 / SVG 实时绘制。
  事实上大部分剧情和美工都是ai绘制，代码也有不少是ai写的，本作品由我一人和ai制作，完全开源，想改什么地方都可以自己改着玩，觉得数值不平衡的自己改就行，代码和注释也已经让ai覆写过了，应该算是比较易懂的了。剩下的应该也没有很大的bug了(或许吧)，希望玩的开心。
